How to read a run
  1. Verdict: did meaning possibly change?
  2. Rewrite marks: tokens that do not trace back to the verbatim.
  3. Findings list: each drop or insert with a category.
  4. Verbatim: confidence bars when the API returns word scores.

The API will transcribe in the language you pick. The drift checker’s word lists are still English-calibrated, so marks may miss or over-fire.
